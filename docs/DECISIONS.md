# Creative Direction

## Concept

The rebuilt portfolio will use an Interactive Systems Workspace concept.

The main hero will contain a stylized low-poly technical environment
representing full-stack development, AI-powered systems, and IT
infrastructure.

## Visual Style

- Dark modern interface
- Stylized low-poly 3D assets
- Cyan primary accent
- Neutral dark materials
- Subtle secondary blue or violet accent
- Professional rather than game-like
- Clean and readable typography

## Hero Scene

The hero scene may contain:

- Main monitor or computer
- Server rack
- Router or network nodes
- Microphone or headset
- Database-inspired objects
- Floating interface panels
- Animated data connections
- Small environmental props

The name, introduction, and action buttons will remain normal HTML.

## Interaction Direction

The initial implementation will use:

- Gentle idle motion
- Pointer-based parallax
- Subtle floating objects
- Hover highlights
- Animated connection lines
- Small object labels

Complex camera journeys, physics, sound, and first-person movement are
outside the initial scope.

## 3D Usage

3D will be strongest in the hero.

Other sections will primarily use normal HTML and CSS for accessibility,
performance, and readability.

## Mobile Direction

Mobile devices will receive a simplified 3D scene or static fallback.

The complete portfolio must remain usable when WebGL is unavailable.

## Asset Policy

- Free assets only
- CC0 preferred
- CC BY permitted with attribution
- GLB or glTF preferred
- Consistent low-poly style
- All sources and licenses documented
- Existing portfolio asset folders remain unchanged

## Decision 002 — Creative Direction

**Date:** 2026-07-29  
**Status:** Approved

The rebuilt portfolio will use an Interactive Systems Workspace concept
with a dark, modern, low-poly visual direction.

The following creative decisions are approved:

1. Use a consistent stylized low-poly 3D asset style.
2. Preserve a dark interface with cyan as the primary accent.
3. Build the hero around a floating systems workspace.
4. Use the hero as the primary 3D experience.
5. Move the main personal photograph treatment to the About section.

Supporting sections will remain primarily HTML and CSS to preserve
readability, accessibility, responsiveness, and performance.
